How a project unfolds

From napkin sketch to shipped screen

The order actually matters here — each stage feeds the next.

  1. Dig in

    Interviews, research, and a lot of "why" questions before a single pixel gets placed.

  2. Sketch wild

    Fast, messy exploration on paper — quantity over polish, on purpose.

  3. Build the system

    Wireframes and components tighten into a coherent, reusable UI kit.

  4. Polish & ship

    Micro-interactions, QA, handoff — the last 10% that makes it feel finished.
